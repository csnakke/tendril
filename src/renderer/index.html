          Editor

          Wrap text
          Wrap long lines to the width of the editor in Edit and Split view, instead of scrolling sideways. Alt+Z
          Tab size
          Spaces inserted by Tab, up to the next tab stop. With several lines selected, Tab indents them and Shift+Tab outdents. In a table, Tab still moves between cells.
          Multiple cursors
          Sublime Text-style editing with several carets at once, in Edit and Split view. Ctrl+click or Alt+click (⌘+click on macOS) adds a caret, dragging adds a selection, Esc returns to one caret. Keyboard shortcuts are listed under Keybindings, where they can be changed.

          Keybindings

          Click a shortcut and press the new keys. Menu shortcuts apply everywhere; the multiple-cursor ones apply in the editor. Shortcuts the desktop reserves (e.g. Ctrl+Alt+↑ on GNOME) never reach the app.

          Images

          Assets folder
          Name of the folder created next to a note to hold inserted images. Links are written as ./assets/name.png.

          Author

          Templates folder

              Backup

              Move Tendril's configuration to a fresh install, or keep a copy before uninstalling.

              Export
              Settings, SSH hosts and their port forwards, trusted hosts, imported themes and the built-in templates, in one .tendril file. Saved keys and passwords stay in pass and are not included; neither are downloaded fonts.
              Import
              Restore a backup. SSH hosts come back without keys or passwords: add those again in Settings › SSH. Tendril restarts to apply it; open tabs are kept.
              From a terminal
              tendril --export <file> and tendril --import <file>. The installer offers both: export before uninstalling, import after installing.

              AI

              Right-click in the editor and choose Prompt Me… to ask a model; its reply is inserted at the cursor, and any selected text is sent along as context. Both providers speak the OpenAI chat API.

              Provider
              Which endpoint answers prompts.
              Server URL
              Base URL of an OpenAI-compatible server: Ollama http://localhost:11434/v1, LM Studio http://localhost:1234/v1, llama.cpp http://localhost:8080/v1.
              Model
              The model name as the server knows it, e.g. llama3.2 or qwen2.5:7b.
              API key
              From openrouter.ai/keys. Stored in the app's settings file, encrypted where the OS has a keychain; it is never read back into the window.
              Model
              An OpenRouter model id, e.g. openai/gpt-4o-mini or anthropic/claude-sonnet-4.
              Connection
              Not tested.
